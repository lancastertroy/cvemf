# Costa Vicentina Early Music Fest '26 — espelho

Cópia de emergência do site oficial **https://costavicentinaemf.pt**.

## Porquê

O domínio `.pt` foi registado a 4 de agosto de 2026. Muitos firewalls corporativos
(FortiGuard e semelhantes) bloqueiam por omissão domínios registados há pouco tempo, na
categoria *Newly Observed Domain*, durante algumas semanas. O domínio `github.io` existe
desde 2008 e não é bloqueado por idade.

Este espelho serve de link alternativo para quem não conseguir aceder ao domínio principal
durante esse período — sobretudo em redes de escritório.

- **Espelho:** https://lancastertroy.github.io/cvemf/
- **Site oficial:** https://costavicentinaemf.pt

## Não indexável

Leva `noindex` e `canonical` para o domínio oficial: não compete com o site principal nos
motores de busca. As etiquetas Open Graph apontam para o próprio espelho, para que a
pré-visualização ao partilhar o link funcione.

## Origem

Cópia de despliegue. A fonte de verdade está em `projects/corvo/costa-vicentina-emf/site/`
e sincroniza-se com `scripts/publish-preview.mjs --mirror`. Não editar aqui à mão.
